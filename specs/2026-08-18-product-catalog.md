# 상품 목록/상세 조회

## 목적 (Why)

모멘티브(강아지 쇼핑몰)의 첫 기능이다. 인증·결제 의존성이 없는 가장 단순한 read-only 기능이라 spec→plan→backend→frontend→배포 전체 파이프라인을 처음으로 검증하는 목적을 겸한다. 동시에 고객이 상품을 둘러볼 수 있어야 이후 장바구니/주문 기능이 의미를 가진다 (`docs/domain-overview.md`의 우선순위 1번).

## 범위 (Scope)

### In Scope
- 상품 목록 조회 (페이지네이션, 최신 등록순 고정)
- 상품 상세 조회
- 품절 여부 뱃지 표시 (boolean)
- 상품당 갤러리형 다중 이미지 (URL 필드, 등록 순서상 첫 번째 이미지가 목록 대표 이미지)
- 정가/할인가(nullable) 표시
- 상품 데이터는 시딩으로 채움

### Out of Scope
- 카테고리 분류, 검색, 정렬/필터 옵션
- 상품 등록/수정 API 및 관리자 화면 (우선순위 6번 관리자 상품 관리에서 다룸)
- 재고 수량 관리/차감 (우선순위 4번 주문/결제에서 다룸)
- 이미지 업로드 기능 (관리자 기능에서 다룸)
- 할인 기간(시작/종료일) 관리
- 장바구니 담기/구매하기 등 상세 페이지 액션 버튼 (우선순위 3번 장바구니 spec에서 추가)

## 사용자 시나리오

1. 사용자가 루트(`/`)에 접속하면 상품 목록 화면이 나타난다 (홈 = 목록).
2. 목록은 최신 등록순으로 정렬되며, 페이지당 20개씩 노출된다.
3. 각 상품 카드는 대표 이미지(등록 순서상 첫 번째 이미지), 상품명, 가격(할인가가 있으면 정가에 취소선 + 할인가 병기), 품절 여부 뱃지를 보여준다.
4. 품절 상품도 목록에서 숨겨지지 않고 계속 노출되며, "품절" 뱃지가 붙는다.
5. 사용자가 상품 카드를 클릭하면 상세 페이지(`/products/{id}`)로 이동한다.
6. 상세 페이지는 해당 상품의 전체 이미지 갤러리, 상품명, 설명, 가격(정가/할인가), 품절 여부를 보여준다. 장바구니/구매 등 액션 버튼은 없다 (순수 조회).
7. 예외 케이스:
   - 등록된 상품이 하나도 없으면 목록 화면에 빈 상태 메시지를 보여준다.
   - 존재하지 않는 상품 id로 상세 페이지에 접근하면 404 처리한다.

## 인터페이스

### API

- `GET /products`
  - Query: `page`(기본값 0), `size`(기본값 20)
  - Response: 상품 목록(각 항목에 대표 이미지 URL, 이름, 가격, 할인가, 품절 여부 포함) + 페이지네이션 메타데이터(전체 개수, 전체 페이지 수 등)
  - 상품이 없으면 빈 배열과 함께 200 응답
- `GET /products/{id}`
  - Response: 상품 상세(이름, 설명, 가격, 할인가, 품절 여부, 이미지 목록 전체를 순서대로)
  - 존재하지 않는 id: 404, 에러 코드 `PRODUCT_NOT_FOUND` (`backend/CLAUDE.md`의 `CustomException(ErrorCode)` 패턴을 따른다)

### 화면

- **목록 페이지 (`/`)**
  - 상품 카드 그리드: 대표 이미지, 이름, 가격/할인가, 품절 뱃지
  - 페이지네이션 UI (20개 단위)
  - 빈 상태: 상품이 없을 때 안내 메시지
  - 로딩 상태: 데이터 fetch 중 로딩 표시
- **상세 페이지 (`/products/{id}`)**
  - 이미지 갤러리 (전체 이미지, 등록 순서대로)
  - 상품명, 설명, 가격/할인가, 품절 여부
  - 액션 버튼 없음
  - 존재하지 않는 id 접근 시 404 페이지

### 데이터 모델

- **Product**
  - `id`: PK
  - `name`: 상품명
  - `description`: 상품 설명
  - `price`: 정가
  - `discountPrice`: 할인가 (nullable, 없으면 정가만 노출)
  - `soldOut`: 품절 여부 (boolean)
  - `createdAt`: 생성일시 (목록 정렬 기준)
- **ProductImage**
  - `id`: PK
  - `productId`: Product FK
  - `url`: 이미지 URL
  - `order`: 노출 순서 (0부터, 가장 작은 값이 대표 이미지)
  - 관계: Product 1 — N ProductImage

## 수용 기준 (Acceptance Criteria)

- [ ] `GET /products`가 페이지네이션(`page`, `size`, 기본값 0/20) 파라미터를 지원하고 최신 등록순으로 정렬된 목록을 반환한다
- [ ] 상품이 하나도 없을 때 `GET /products`가 빈 배열과 200 응답을 반환하고, 목록 화면은 빈 상태 메시지를 보여준다
- [ ] `GET /products/{id}`가 존재하지 않는 id에 대해 404와 `PRODUCT_NOT_FOUND` 에러 코드를 반환하고, 상세 페이지는 이를 404로 처리한다
- [ ] 목록 화면의 각 카드가 대표 이미지(등록 순서상 첫 번째), 상품명, 가격(할인가 있으면 정가+할인가 병기), 품절 뱃지를 표시한다
- [ ] 품절 상품이 목록에서 숨겨지지 않고 "품절" 뱃지와 함께 노출된다
- [ ] 상세 페이지가 해당 상품의 전체 이미지 갤러리(등록 순서대로), 이름, 설명, 가격/할인가, 품절 여부를 표시하며 장바구니/구매 등 액션 버튼을 포함하지 않는다
- [ ] 상품 데이터가 시딩(직접 삽입 또는 시드 스크립트)으로 채워지며, 별도 등록 API/화면은 존재하지 않는다
