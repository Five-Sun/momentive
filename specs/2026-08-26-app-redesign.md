# 앱 전체 재디자인 (7개 화면)

## 목적 (Why)

Claude Design 핸드오프 프로젝트(claude.ai/design 프로젝트 `f05007c9-8716-43a5-b06f-1982d8a1b595`, `design_handoff_momentive_app/`)를 통해 홈·카테고리·검색·상품상세·장바구니·위시리스트·마이 7개 화면 전체와 그에 필요한 컴포넌트·디자인 토큰이 high-fidelity로 완성됐다. 현재 구현은 홈 화면(단순 버전, `specs/2026-08-23-home-screen.md`)과 최소 기능만 있는 상품상세 페이지뿐이고, 나머지 화면은 존재하지 않는다. 이 스펙은 핸드오프 디자인을 근거로 Next.js + Tailwind 프로덕션 코드로 7개 화면을 재구현해, 실사용자가 있는 커머스 앱다운 완성도를 갖추기 위함이다.

## 범위 (Scope)

### In Scope
- 7개 화면 신규/재구현: 홈(`/`), 카테고리(`/category`), 검색(`/search`), 상품상세(`/products/[id]`), 장바구니(`/cart`), 위시리스트(`/wishlist`), 마이(`/mypage`)
- 하단 네비게이션을 5탭(홈/카테고리/검색/위시/마이)으로 전환 — `specs/2026-08-25-app-shell.md`가 만든 4탭(홈/검색/장바구니/마이페이지) 구성을 대체. 480px 프레임 인프라 자체는 `app-shell` spec 그대로 유지, 이 스펙은 그 안의 콘텐츠와 BottomNav 탭 구성만 바꾼다
- `Product` 백엔드 확장: `category` 필드 추가, `GET /products`에 `sort` 쿼리 파라미터 추가(신상순 기본값 / 낮은 가격순 / 높은 가격순, 인기순은 신상순과 동일하게 동작)
- 핸드오프 디자인 토큰(`tokens/*.css`) 반영 및 신규 컴포넌트(`FilterSheet`, `ReviewCard`, `ShippingProgress`) 도입
- 유니코드 글리프 아이콘을 실제 아이콘 세트(예: `lucide-react`)로 교체
- 위시리스트·장바구니·최근 본 상품을 `localStorage` 기반으로 실제 토글/영속화 (기기 간 동기화는 로그인 도입 전까지 불가 — 알려진 한계)
- 검색: 자동완성(클라이언트에 로드된 상품명 매칭), 최근검색어(`localStorage`), 인기검색어(하드코딩 목업)
- 상품상세: 사이즈 셀렉터(전 상품 공통 고정 세트 S/M/L/XL), 사이즈 가이드/배송·교환 안내 아코디언(정적 콘텐츠), 리뷰 리스트(전 상품 공통 목업 3~4개)
- 마이페이지: 프로필(하드코딩 닉네임/아바타), 위시/장바구니/주문 카운트 요약(위시·장바구니는 실카운트, 주문은 0 고정), 메뉴 리스트(UI만, 무동작)

### Out of Scope
- 로그인/회원가입(Auth) 도메인 — 마이페이지 프로필은 하드코딩 표시로 대체
- 실제 결제(토스페이먼츠 연동) 및 Order 도메인 — 장바구니 "결제" 버튼은 무동작/"준비중" 처리만 하고, 실 연동은 별도 spec에서 다룸
- Review/Coupon 백엔드 도메인 — 리뷰는 프론트 목업, 쿠폰은 고정 3천원 할인 토글로 하드코딩 (실 쿠폰 코드 시스템 없음)
- 사이즈별 실재고 관리 — 전 상품 공통 고정 사이즈 세트만 표시, 사이즈별 품절 상태 없음
- 마이페이지 메뉴 항목(배송조회/쿠폰함/적립금/반려견 프로필 관리/고객센터)의 실제 기능 — UI 배치만, 탭해도 동작 없음
- 인기검색어/인기순 정렬의 실제 집계 로직 — 각각 하드코딩 목업과 신상순 대체로 처리 (실 집계 인프라는 별도 spec)
- PWA 대응(manifest, 서비스워커 등)

## 사용자 시나리오

### 공통: 하단 네비게이션
모든 화면(`/style-guide` 제외, `app-shell` spec 그대로) 하단에 홈·카테고리·검색·위시·마이 5탭이 고정 표시된다. 현재 경로에 해당하는 탭은 `brand-pink-active` 색상 + 굵은 글씨로 강조되고, `/products/[id]`처럼 5개 경로 어디에도 속하지 않는 화면에서는 모든 탭이 비활성 상태다.

### 1. 홈 (`/`)
1. 로고 + 장바구니 아이콘 헤더 → 검색바(탭하면 `/search`로 이동) → 프로모 배너(핑크 그라디언트, 정적 카피) → "지금 인기 있는" 가로스크롤 랭킹(리뷰 많은순 상위 4개에 순위 배지 — 실 리뷰 집계가 없으므로 목업 정렬 기준 사용) → 카테고리 칩 필터(탭하면 해당 카테고리로 상품 그리드 필터링) → 2열 상품 그리드 → "최근 본 상품" 가로스크롤(상품상세 방문 시 누적, 최대 8개, `localStorage`)
2. 그리드는 항상 2열 고정(`app-shell` spec 그대로), 하단 스크롤 도달 시 다음 페이지 자동 로드(무한스크롤, 기존 동작 유지)
3. 예외: 상품 0개면 빈 상태 문구. 이미지 로드 실패 시 `surface-strong` 배경 + 상품명 플레이스홀더(기존 패턴 재사용). "최근 본 상품"이 비어 있으면 해당 섹션 자체를 렌더링하지 않음.

### 2. 카테고리 (`/category`)
1. 아우터/니트/이너웨어/악세서리 4개 리스트 항목(각 설명 텍스트 포함)이 세로로 나열된다.
2. 항목을 탭하면 `/search?category={값}`으로 이동해 해당 카테고리로 필터링된 검색 결과 화면을 보여준다.

### 3. 검색 (`/search`)
1. 검색바가 자동 포커스된 상태로 진입한다.
2. 입력 중이고 아직 검색을 실행(Enter/클릭)하지 않았을 때: 클라이언트에 로드된 상품명과 매칭되는 자동완성 드롭다운(최대 5개)이 뜬다.
3. 입력값이 없을 때: 최근검색어 칩(`localStorage`, 탭하면 해당 검색어로 재검색) + 인기검색어 순위 리스트(1~3위 핑크 숫자, 하드코딩 목업)를 보여준다.
4. 검색을 실행하면 결과 개수 + 정렬 버튼(`FilterSheet` 바텀시트 오픈: 인기순/신상순/낮은 가격순/높은 가격순, 인기순은 신상순과 동일 결과)과 2열 상품 그리드가 나타난다. `/category`에서 진입한 경우 해당 카테고리로 결과가 미리 필터링돼 있다.
5. 예외: 검색 결과 0개면 빈 상태 문구. 자동완성 매칭 0개면 드롭다운을 표시하지 않음.

### 4. 상품상세 (`/products/[id]`)
1. 헤더(뒤로가기, 위시 하트 — 탭하면 위시리스트 실제 토글) → 이미지 갤러리(등록된 이미지 전체, 기존 구현 유지) → 제목/평점(더미 고정값)/가격(할인가 있으면 정가 취소선 병기) → 사이즈 셀렉터(S/M/L/XL 고정 세트) + "사이즈 가이드" 토글(체중/등길이 정적 표) → "배송·교환/반품 안내" 아코디언(정적 콘텐츠, 사이즈 가이드와 동일 state로 토글 — 동시에 하나만 열림) → 상품설명 → 리뷰 리스트(전 상품 공통 목업 3~4개, `ReviewCard` 사용) → 하단 고정 CTA(위시 담기 + 장바구니 담기)
2. "장바구니 담기" 탭 시 장바구니에 담기고(사이즈 선택 필수) Toast 1.8초 노출 후 자동 소멸.
3. 예외: 존재하지 않는 id는 기존처럼 `notFound()` 404. 품절 상품은 사이즈 셀렉터 비활성 + 장바구니 담기 버튼 비활성.

### 5. 장바구니 (`/cart`)
1. `ShippingProgress`(무료배송까지 남은 금액, 5만원 기준: `remaining = max(0, 50000 - (subtotal - discount))`, 0이면 "무료배송 조건 달성" 메시지) → 아이템 리스트(썸네일/사이즈/수량스테퍼/가격/삭제, `localStorage` 영속) → 쿠폰 적용 토글(고정 3천원 할인) → 금액 요약(상품금액/할인/배송비/총액) → 하단 고정 "결제" 버튼
2. "결제" 버튼은 이번 스펙에서는 무동작(또는 "준비중" 토스트만 노출) — 실제 결제 연동은 범위 밖.
3. 예외: 장바구니가 비어 있으면 빈 상태 문구 + 홈으로 이동 유도.

### 6. 위시리스트 (`/wishlist`)
1. 헤더 + 즐겨찾기한 상품 2열 그리드(`ProductCard` 재사용, `localStorage` 기반 실제 데이터).
2. 하트 버튼을 다시 탭하면 위시에서 제거된다.
3. 예외: 위시가 비어 있으면 빈 상태 문구.

### 7. 마이 (`/mypage`)
1. 프로필(하드코딩 아바타 이미지 + 닉네임) → 주문/위시/장바구니 카운트 요약 바(위시·장바구니는 `localStorage` 기준 실카운트, 주문은 0 고정) → 메뉴 리스트(배송조회/쿠폰함/적립금/반려견 프로필 관리/고객센터 — 탭해도 무동작).

## 인터페이스

### API

**`GET /products`** — 기존 계약(`specs/2026-08-18-product-catalog.md`)에 파라미터 추가
- 신규 쿼리 파라미터: `category`(선택, 문자열 — `OUTER`/`KNIT`/`INNERWEAR`/`ACCESSORY`), `sort`(선택, 기본값 `new` — `new`/`popular`/`price_asc`/`price_desc`. `popular`은 `new`와 동일한 정렬 결과를 반환)
- 응답 형태는 변경 없음 (기존 페이지네이션 메타데이터 유지)

**`GET /products/{id}`** — 변경 없음

신규 백엔드 API 없음 (장바구니/위시리스트/리뷰/쿠폰/검색은 전부 프론트 로컬 처리, 위 상세 참조).

### 화면

각 화면의 컴포넌트 구성은 위 "사용자 시나리오" 절 참조. 공통 원칙:
- 모든 화면은 `app-shell` spec의 480px 프레임 + `(shell)` route group 안에 위치 (`/style-guide` 제외 원칙 동일 유지)
- `BottomNav`는 홈(`/`, ⌂)/카테고리(`/category`, ▤)/검색(`/search`, ⌕)/위시(`/wishlist`, ♥)/마이(`/mypage`, ☺) 5탭으로 재구성. 아이콘은 실제 아이콘 세트로 교체(Known gaps 처리)
- 신규 컴포넌트: `FilterSheet`(`components/commerce/`), `ReviewCard`(`components/commerce/`), `ShippingProgress`(`components/feedback/`) — 핸드오프의 `.jsx`/`.d.ts`/`.prompt.md`를 프롭 시그니처 기준으로 참고해 기존 컴포넌트들과 동일한 패턴(TypeScript, `src/components/<category>/`)으로 이식

### 데이터 모델

**`Product`** (기존 엔티티 확장)
- 신규 필드: `category` (enum 또는 문자열: `OUTER` | `KNIT` | `INNERWEAR` | `ACCESSORY`)
- 기존 필드(`id`/`name`/`description`/`price`/`discountPrice`/`soldOut`/`createdAt`/`images`) 변경 없음

**프론트 전용 상수/로컬 상태** (백엔드 모델 아님)
- 사이즈 옵션: 전 상품 공통 고정 배열 `['S', 'M', 'L', 'XL']`
- 리뷰 목업: 전 상품 공통 고정 배열 (author/rating/date/text/photoCount, 3~4건)
- 인기검색어 목업: 고정 문자열 배열 (1~3위)
- `localStorage` 키: 위시리스트(상품 id 배열), 장바구니(`{key, id, title, size, unitPrice, qty}[]`), 최근 본 상품(최근 8개, 중복 제거 후 최상단 삽입), 최근검색어

## 수용 기준 (Acceptance Criteria)

### 공통
- [x] 모든 화면(`/style-guide` 제외)에서 하단 네비게이션이 홈/카테고리/검색/위시/마이 5탭으로 표시되고, 현재 경로에 해당하는 탭만 활성 스타일로 강조된다

- [x] 아이콘이 유니코드 글리프 대신 실제 아이콘 세트로 표시된다

### 홈
- [x] 프로모 배너, 인기 랭킹 가로스크롤(순위 배지 포함), 카테고리 칩 필터, 최근 본 상품 가로스크롤이 헤더와 상품 그리드 사이/아래에 순서대로 표시된다

### 카테고리
- [x] `/category`에 4개 카테고리 리스트 항목이 설명과 함께 표시된다
- [x] 카테고리 항목 탭 시 해당 카테고리로 필터링된 검색 결과 화면으로 이동한다

- [x] 입력 중 상품명이 매칭되면 자동완성 드롭다운(최대 5개)이 표시된다

- [x] 사이즈 셀렉터(S/M/L/XL)가 표시되고, 품절 상품은 셀렉터와 장바구니 담기 버튼이 비활성화된다
- [x] 사이즈 가이드 토글과 배송·교환 안내 아코디언이 동시에 하나만 열린다

- [x] 위시 하트 버튼 탭 시 위시리스트에 실제로 추가/제거된다
