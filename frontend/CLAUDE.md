# 모멘티브 프론트엔드

Next.js. Vercel 배포 (Root Directory: `frontend/`, Ignored Build Step으로 경로 필터링).

## 스택
- Next.js, TypeScript
- 백엔드 API: `NEXT_PUBLIC_API_BASE_URL` 환경변수로 주입 (api.모멘티브도메인)

## 컨벤션 (첫 기능 구현하며 채워나갈 것 — 지금은 뼈대만)
- 컴포넌트 디렉토리 구조
- API 호출 방식 (fetch wrapper 등)
- 스타일링 방식

## 검증 방법
- `npm run build`로 빌드 확인
- `npm run lint`
