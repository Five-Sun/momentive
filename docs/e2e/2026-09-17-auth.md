# 인증 로그인 요청 흐름 E2E 케이스

## 시나리오 1: 회원가입 후 로그인 상태가 새로고침 뒤에도 유지된다

spec 사용자 시나리오 1·2·6과 AC "회원가입 즉시 로그인", "정상 로그인 후 마이페이지 반영"을 근거로, 신규 계정 생성부터 마이페이지 표시 및 동일 브라우저 세션의 새로고침까지 확인한다.

**사전조건**: 로컬 DB에 테스트 계정이 없어도 된다. 실행 스크립트가 타임스탬프 기반 이메일로 계정 한 개만 생성한다.

**판정 기준**: 회원가입 직후와 `/mypage` 새로고침 뒤 모두 생성한 닉네임과 "로그아웃" 버튼이 보인다.

## 시나리오 2: 존재하는 계정의 틀린 비밀번호와 존재하지 않는 이메일은 같은 오류를 보인다

spec 사용자 시나리오 2와 AC "계정 존재 여부를 구분하지 않는 INVALID_CREDENTIALS"를 근거로, 시나리오 1에서 만든 계정과 존재하지 않는 이메일에서 같은 로그인 오류를 확인한다.

**사전조건**: 시나리오 1의 로그인 세션과 생성된 이메일을 이어받는다.

**판정 기준**: 두 시도 모두 `/login`에 머물고 "이메일 또는 비밀번호가 일치하지 않아요"가 보인다.

## 시나리오 3: Access 쿠키가 없으면 refresh 후 일반 사용자의 관리자 접근을 차단한다

spec 사용자 시나리오 3의 자동 갱신과 `docs/request-flow-login.md`의 `/admin` 클라이언트 인가 경로를 근거로, Access 쿠키만 지운 상태에서 `AdminGuard`의 `/auth/me` 요청이 refresh를 거쳐 일반 사용자 접근을 홈으로 되돌리는지 확인한다.

**사전조건**: 시나리오 1에서 생성한 일반 사용자 세션을 이어받는다. 스크립트가 `access_token`만 지우며 `refresh_token`은 유지한다.

**판정 기준**: `/auth/refresh` 응답이 정확히 1회 200이고, `/admin`에서 관리자 콘텐츠가 노출되지 않은 채 `/`로 이동한다.

## 시나리오 4: 비로그인 사용자의 관리자 접근은 홈으로 이동한다

`docs/request-flow-login.md`의 `AdminGuard` 및 `SecurityConfig` 인가 규칙을 근거로, 쿠키가 전혀 없는 상태의 `/admin` 접근 UX를 확인한다.

**사전조건**: 시나리오 3의 페이지에서 쿠키를 모두 제거한다.

**판정 기준**: "관리자 권한을 확인하는 중이에요"가 장시간 남지 않고 `/`로 이동하며 관리자 화면 텍스트가 보이지 않는다.

## 스킵 항목

- Refresh Token 자체의 만료·재사용·동시 401 요청은 브라우저에서 시간을 14일 경과시키거나 토큰을 재사용 상태로 조작할 수 있는 안전한 UI/API 준비 절차가 없어 이번 단일 흐름에서 제외한다. Access 쿠키 삭제 후 자동 refresh 1회는 시나리오 3으로 검증한다.
- ADMIN 계정의 `/admin` 정상 진입은 이 인증 plan의 대상이 아니며, 로컬 DB 역할 승격 절차가 필요한 관리자 기능 E2E에서 검증한다. 이번 문서는 일반 사용자 및 비로그인 차단만 다룬다.

## 실행 스크립트

```javascript
const page = await browser.getPage("auth");
const stamp = Date.now();
const email = `e2e-auth-${stamp}@momentive.test`;
const password = "password123";
const nickname = `e2e-${stamp}`;
const loginError = "\uC774\uBA54\uC77C \uB610\uB294 \uBE44\uBC00\uBC88\uD638\uAC00 \uC77C\uCE58\uD558\uC9C0 \uC54A\uC544\uC694";

async function fail(scenario, message) {
  const path = await saveScreenshot(await page.screenshot(), `auth-scenario-${scenario}-fail.png`);
  throw new Error(`시나리오 ${scenario} 판정 기준 미충족: ${message} (url=${page.url()}, screenshot: ${path})`);
}

// --- 시나리오 1 ---
await page.goto("http://localhost:3000/signup", { waitUntil: "domcontentloaded" });
await page.getByLabel("\uC774\uBA54\uC77C").fill(email);
await page.getByRole("textbox", { name: "\uBE44\uBC00\uBC88\uD638" }).fill(password);
await page.getByLabel("\uB2C9\uB124\uC784").fill(nickname);
await page.getByRole("button", { name: "\uD68C\uC6D0\uAC00\uC785" }).click();
await page.waitForURL("**/mypage", { timeout: 10000 });
await page.waitForTimeout(300);
if (!(await page.getByText(`${nickname}\uB2D8`).isVisible())) {
  await fail(1, "회원가입 직후 로그인 상태가 마이페이지에 표시되지 않음");
}
await page.reload({ waitUntil: "domcontentloaded" });
if (!(await page.getByText(`${nickname}\uB2D8`).isVisible())) {
  await fail(1, "새로고침 후 로그인 세션이 유지되지 않음");
}
console.log("PASS: 시나리오 1 - 회원가입 후 로그인 상태 및 새로고침 세션 유지");

// --- 시나리오 2 ---
await page.goto("http://localhost:3000/login", { waitUntil: "domcontentloaded" });
await page.getByLabel("\uC774\uBA54\uC77C").fill(email);
await page.getByRole("textbox", { name: "\uBE44\uBC00\uBC88\uD638" }).fill("wrongpassword1");
await page.getByRole("button", { name: "\uB85C\uADF8\uC778" }).click();
await page.waitForTimeout(300);
if (!page.url().includes("/login") || !(await page.getByText(loginError).isVisible())) {
  await fail(2, "존재하는 계정의 틀린 비밀번호에 공통 오류가 표시되지 않음");
}
await page.getByLabel("\uC774\uBA54\uC77C").fill(`missing-${stamp}@momentive.test`);
await page.getByRole("textbox", { name: "\uBE44\uBC00\uBC88\uD638" }).fill(password);
await page.getByRole("button", { name: "\uB85C\uADF8\uC778" }).click();
await page.waitForTimeout(300);
if (!page.url().includes("/login") || !(await page.getByText(loginError).isVisible())) {
  await fail(2, "존재하지 않는 이메일에 동일 공통 오류가 표시되지 않음");
}
console.log("PASS: 시나리오 2 - 로그인 실패 시 계정 존재 여부를 노출하지 않음");

// --- 시나리오 3 ---
await page.getByLabel("\uC774\uBA54\uC77C").fill(email);
await page.getByRole("textbox", { name: "\uBE44\uBC00\uBC88\uD638" }).fill(password);
await page.getByRole("button", { name: "\uB85C\uADF8\uC778" }).click();
await page.waitForURL("**/mypage", { timeout: 10000 });
const cookies = await page.context().cookies();
const accessCookie = cookies.find((cookie) => cookie.name === "access_token");
if (!accessCookie) await fail(3, "로그인 후 access_token 쿠키가 없음");
await page.context().clearCookies();
await page.context().addCookies(cookies.filter((cookie) => cookie.name !== "access_token"));
let refreshResponses = 0;
let refreshOk = 0;
page.on("response", (response) => {
  if (response.url().includes("/auth/refresh")) {
    refreshResponses += 1;
    if (response.status() === 200) refreshOk += 1;
  }
});
await page.goto("http://localhost:3000/admin", { waitUntil: "domcontentloaded" });
await page.waitForURL("http://localhost:3000/", { timeout: 10000 });
if (refreshResponses !== 1 || refreshOk !== 1 || page.url() !== "http://localhost:3000/") {
  await fail(3, `refresh 응답=${refreshResponses}, 200 응답=${refreshOk}`);
}
console.log("PASS: 시나리오 3 - Access 쿠키 손실 후 refresh 1회 및 일반 사용자 관리자 차단");

// --- 시나리오 4 ---
await page.context().clearCookies();
await page.goto("http://localhost:3000/admin", { waitUntil: "domcontentloaded" });
await page.waitForURL("http://localhost:3000/", { timeout: 10000 });
if (page.url() !== "http://localhost:3000/") {
  await fail(4, "비로그인 관리자 접근이 홈으로 이동하지 않거나 확인 화면에 멈춤");
}
console.log("PASS: 시나리오 4 - 비로그인 관리자 접근 차단");
```
