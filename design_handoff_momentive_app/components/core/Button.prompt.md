Pill-shaped button, the primary CTA across Momentive — "장바구니 담기", "구매하기", "필터 적용".

```jsx
<Button variant="primary">장바구니 담기</Button>
<Button variant="secondary" size="sm">전체보기</Button>
```

Variants: `primary` (brand pink fill, used once per screen for the hero action), `secondary` (outline, for secondary actions), `ghost` (underlined text, for tertiary/dismiss actions). Always fully rounded — Momentive has no square buttons.
